# Luna's Word Moon

A word game for young readers: read it, know what it means, spell it, and fill the moon.

Play: https://deklerkdan.github.io/word-moon/

- Works in any modern browser. On a phone, use the browser menu's "Add to Home screen" (or "Install app") to keep it like an app.
- Reading aloud uses the device's own voices. Grown-ups (the gear button) has a voice picker and tips for nicer voices.
- Progress is saved on the device, per name. Grown-ups › Backup copies a code to move progress to another device.

This folder is the published copy. It is built from the source in the LightRain workbench (`Homeschool/word-moon`, `node build.js`); don't edit `index.html` here by hand.
